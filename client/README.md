# Doctor Tracker — App

The browser part of Doctor Tracker. Built with Next.js and shadcn/ui.

## Run it

1. `pnpm install`
2. `pnpm dev`
3. Open http://localhost:3000

The server must be running too — the app needs it for login and data.

## Configuration

Copy `.env.example` to `.env` and set `NEXT_PUBLIC_API_URL` to point at the server (default: `http://localhost:5000/api`).
